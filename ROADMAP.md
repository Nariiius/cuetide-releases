# Roadmap

The current focus is addressing reproducible reliability and compatibility problems in the initial public release.

There are no announced feature milestones or delivery dates. This page is intentionally small rather than a list of speculative promises.

Suggest improvements through [feature requests](https://github.com/Nariiius/cuetide-releases/issues/new/choose). Check existing issues first. Requests and discussion do not mean a feature is accepted or scheduled; confirmed changes will be described in release notes.
